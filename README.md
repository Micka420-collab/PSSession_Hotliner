# Remote Session Manager (RSM) Pro

Utilitaire de gestion de sessions distantes et d'administration système via PowerShell.

## 🚀 Installation & Déploiement

> [!IMPORTANT]
> **Le logiciel ne doit pas être lancé directement depuis le serveur.**
> Pour garantir un fonctionnement optimal et éviter les lenteurs réseau, vous devez impérativement le copier sur votre poste local.

1. Accédez au dossier source : `\\RES017\StockageTemp\3150\Logiciel PSSession`
2. Copiez l'intégralité du contenu sur votre bureau ou dans un dossier local (ex: `C:\Outils\RSM`).

## 🛠️ Utilisation

Pour lancer le logiciel avec les droits nécessaires :

1. Double-cliquez sur le fichier **`Lanceur.cmd`**.
2. Le script s'exécutera automatiquement en mode Administrateur.
3. La fenêtre PowerShell sera masquée pour laisser place uniquement à l'interface graphique.

## ✨ Fonctionnalités Principales

- **Gestion de Session** : Connexion rapide par numéro de poste (PRT) ou nom complet.
- **Outils de Diagnostic** : Ping, accès console externe, informations système.
- **Nettoyage Automatique** : Option de suppression du profil admin local après déconnexion pour libérer de l'espace.
- **Historique** : Navigation dans l'historique des commandes avec les touches ↑ et ↓.

## 📋 Prérequis

- Windows 10/11.
- Droits d'administration sur le poste local et distant.
- PowerShell 5.1 (intégré par défaut).
